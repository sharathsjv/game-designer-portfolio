# Sharath Sajeev – game design portfolio

Static site. No build step.

Upload everything in this folder to the root of a public GitHub repo named
`sharathsjv.github.io`, then turn on Pages (Settings > Pages > Deploy from branch > main / root).
The site will be live at https://sharathsjv.github.io

Pages: index.html, everyday-objects.html, f2p.html, midnight-express.html. Images are in img/.

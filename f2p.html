Falcon Dash

A spawn system driven by distance

A three-lane endless runner. I owned the level design: the logic that places obstacles, powerups and coins.

  • Distance drives everything. The run is split into a set number of phases, each covering a range of distance.
  • Each phase defines which obstacles, powerups and coins can appear, and how often each one spawns.
  • The system mixes hand-authored patterns with random spawns.
  • After the last phase, the cycle starts again.

Personal balancing exercise

Economy teardown: Candy Crush

I broke down Candy Crush's economy to see how a fair free-to-play loop is built. Gold bars are the main currency, earned by finishing chapters or bought in the store. Hearts recharge on their own and gold bars are handed out regularly, so players never have to rely on purchases to keep playing.

Weapon stat sheet

For a combat design test, I set stats for ten weapons across five classes, each in a common and a rare version: handling, movement speed, fire rate, reload, aim assist, recoil, damage falloff, body-part multipliers and dispersion. Common versions shown.
